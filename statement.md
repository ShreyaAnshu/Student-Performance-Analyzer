# College Performance Analyzer

## Project Overview

The College Performance Analyzer is a Python-based project designed to calculate and analyze the academic performance of college students.

The system collects student profile details, subject details, credits, and grade points. It calculates semester-wise SGPA and overall CGPA and then analyzes the student's performance based on the calculated CGPA.

The project uses a modular structure where different tasks are handled by separate Python modules.

## Problem Statement

College students often need to calculate and monitor their academic performance across multiple semesters. Manual calculation of SGPA and CGPA can be time-consuming and may lead to calculation errors, especially when subjects have different credit values.

The College Performance Analyzer provides a simple and systematic way to enter academic information, calculate SGPA and CGPA, and obtain performance feedback.

## Scope of the Project

The project includes:

- Collecting student profile details.
- Entering subject names, credits, and grade points.
- Calculating semester-wise SGPA.
- Storing semester-wise SGPA and total credits.
- Calculating overall CGPA.
- Analyzing performance based on CGPA.
- Providing performance grade and feedback.
- Supporting multiple semesters.
